# Contract gaps — known cases and recommended extensions

The contract (`app/lib/arcade/types.ts`, `keyboard.ts`, `GameCanvas.tsx`) was designed with asteroides. Every extension must be **additive**: asteroides keeps behaving exactly as before, and the spec carries a regression criterion proving it.

Always check the current code first: an earlier game spec may already have added the extension. In that case it is not a gap any more — reuse it.

**Kind:**

- `decision` — there are real alternatives. Ask it as a question with the recommendation below, and record the answer in **Decisiones**.
- `notice` — there is no real alternative. State it once as what the spec will do, record it in **Decisiones**, and do not ask it as a question. The user can still object.

| Gap                                  | Kind                     | How it shows in a reference                                                                                                                                                      | Recommended minimal extension                                                                                                                                                                                                   | Discarded (and why)                                                                                                      | Regression criterion                            |
| ------------------------------------ | ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------- |
| **No lives**                         | decision                 | No `lives` variable; ends on top-out or a timer                                                                                                                                  | `lives: number \| null` in `ArcadeSnapshot`; `GamePlayerScreen` hides Vidas when `null`                                                                                                                                         | `lives: 1` (lies in the HUD), `lives: 0` (renders "—" as if dead)                                                        | asteroides HUD still shows hearts               |
| **Key auto-repeat**                  | decision, **per action** | Acts on every `keydown`, so the OS repeat drives it (e.g. moving a piece)                                                                                                        | Additive `typed(code)` in `keyboard.ts` that counts repeats and is consumed on read; `pressed()` unchanged. Per action: `typed()` where the original repeats (1:1 default), `pressed()` only where the user picks the exception | Changing `pressed()` (changes asteroides' fire rate), a custom DAS/ARR (new mechanic)                                    | asteroides holding Space fires one bullet       |
| **Keys outside `GAME_KEYS`**         | decision                 | Uses keys that scroll or type, beyond arrows and Space (letters that type nothing do not count)                                                                                  | `gameKeys?: string[]` in `ArcadeGameModule`, merged by `GameCanvas` with its default set                                                                                                                                        | Hard-coding the keys in `GameCanvas` (it must not know games)                                                            | `git diff` of the default set is empty          |
| **Mouse / pointer**                  | decision                 | `mousemove`, `click` on the canvas                                                                                                                                               | The engine listens to `pointermove` on the canvas it receives, with coordinates scaled by `width / rect.width`; `destroy()` removes it                                                                                          | Listening on `document` (breaks pause-on-click-outside)                                                                  | asteroides ignores the mouse                    |
| **Victory**                          | decision                 | "You win" / last level cleared                                                                                                                                                   | Goes to `gameover` with the final score; the modal does not change                                                                                                                                                              | A new `won` status (touches the HUD and the modal)                                                                       | asteroides `gameover` unchanged                 |
| **Extra HUD value**                  | decision                 | Lines, combo, timer in the DOM                                                                                                                                                   | Drawn inside the canvas next to the board (it is not in the DOM HUD, so nothing is duplicated)                                                                                                                                  | A field in `ArcadeSnapshot` (game-specific data in the common contract), a per-game HUD (components would know ids)      | —                                               |
| **Not 4:3 / second canvas**          | decision                 | e.g. a 300×600 board + a 120×120 preview                                                                                                                                         | A single canvas at 800×600 with the board centred and the side panels drawn inside; the physics stays in its units                                                                                                              | A variable-aspect CRT for a single game                                                                                  | asteroides frame unchanged                      |
| **Images / sprites**                 | decision                 | `new Image()`, a spritesheet                                                                                                                                                     | Files in `public/games/<id>/`, loaded inside the engine; the loop does not draw sprites until they load. Only assets the user owns (the references are theirs); never art copied from a commercial game                         | Importing them through the bundler (the engine is a plain TS module), drawing with shapes instead (also valid: offer it) | —                                               |
| **Sound**                            | decision                 | `new Audio()`                                                                                                                                                                    | Out by default (spec 05); its own spec if wanted                                                                                                                                                                                | Mixing in autoplay and volume policy here                                                                                | `grep -rn "Audio" app/lib/arcade/` empty        |
| **Frame-rate dependency**            | notice                   | Per-frame physics without `dt`, or a timer that resets (`acc = 0`) instead of subtracting (`acc -= interval`)                                                                    | Multiply by `dt` / subtract the interval, so it plays the same at 60 and 120 Hz (as `DRAG` in spec 05)                                                                                                                          | —                                                                                                                        | —                                               |
| **Its own pause/restart keys**       | notice                   | `P`, `R`, Space to restart, a restart button                                                                                                                                     | Drop them: the wrapper owns pause (Esc + PAUSA) and restart (JUGAR DE NUEVO)                                                                                                                                                    | Keeping them (two pause paths, the engine listening while paused)                                                        | `P` does nothing                                |
| **Clicks inside the canvas**         | notice                   | Buttons drawn on the canvas (level selector, restart)                                                                                                                            | Drop them; debug tools such as a level jump are out                                                                                                                                                                             | —                                                                                                                        | —                                               |
| **Score out of range**               | notice                   | Floats, or no ceiling (can in theory exceed 10.000.000)                                                                                                                          | `Math.floor` + clamp to `[0, 10000000]` in the engine                                                                                                                                                                           | Relaxing the `scores` check (a schema change)                                                                            | —                                               |
| **Theme / `localStorage`**           | notice                   | Light/dark toggle, a local best score                                                                                                                                            | Drop them; the platform owns theme and scores                                                                                                                                                                                   | —                                                                                                                        | `grep -rn "localStorage" app/lib/arcade/` empty |
| **Starting key leaks into the game** | notice                   | `GameCanvas` calls `start()` inside the `keydown` that starts the game, and the engine attaches its `window` keyboard during that same event, so the key can read as `pressed()` | The new engine calls `keyboard.clear()` right after `attach()` in `start()` (or ignores input until its first `update`). Only in the new engine: asteroides is not touched                                                      | —                                                                                                                        | —                                               |
| **Draw cut on game over**            | notice                   | The loop returns before `draw()` once over                                                                                                                                       | One explicit `draw()` when entering `gameover`                                                                                                                                                                                  | —                                                                                                                        | —                                               |
